## Описание проекта

**BINinfo** — это приложение для Android, которое позволяет пользователям получать информацию о банковских картах на основе введенного BIN (Bank Identification Number). Приложение подключается к открытое API [binlist.net](https://binlist.net/) для получения данных о карте, а также сохраняет историю запросов для удобного доступа в будущем.

## Основные функции

### Первый экран
- Пользователь вводит BIN банковской карты и нажимает кнопку "Отправить".
- Информация о карте включает:
  - Страна
  - Координаты
  - Тип карты (Visa, MasterCard и др.)
  - Данные о банке (URL, телефон, сайт, город)

### Второй экран
- Список истории запросов BIN номеров, которые были получены из API.
- История запросов сохраняется при перезапуске приложения.

## Технологический стек

- **Архитектура**: MVVM (Model-View-ViewModel)
- **Асинхронные операции**: Coroutines
- **UI**: Jetpack Compose
